# thbigmatome デザインガイド

**バージョン**: 1.1
**作成日**: 2026-02-21
**改訂**: 2026-10-31（色の役割・トークン・アイコン体系・勝敗表示・主ボタンの色を改定。方針転換を含む）
**対象**: フロントエンド（Vue.js 3 + Vuetify 3）

---

## 概要

**テーマコンセプト**: 東方 × 野球融合 — 和風の落ち着き × スポーツの躍動感
**ターゲット**: PC優先、CUIゲーマー・ベテラン野球ファン向け
**情報設計方針**: 高密度テーブル主体、視認性と操作効率を両立する

### 方針転換（2026-10-31）

当初は事務用途のアプリとして、色とアイコンを絞り、区別を文字に任せていた（あえて地味に作る方針）。トレンドの変化を受け、**色分けとアイコンを使って、見やすく・わかりやすくする**方針に改めた。派手にするのではなく、次の 4 原則を守る。

1. **1 つの色相に 1 つの意味。** 同じ画面に出る意味どうしは、色相・アイコン・形のどれかで分ける
2. **色だけに意味を背負わせない。** どの色にも、アイコンか文字（または線種）を併用する（色覚差・暗い画面・印刷）
3. **暖色（赤・黄・橙・桃）は「注意が要る印」専用。** 区分や種類の識別は寒色と無彩色で行う。例外は勝敗（慣習を優先。「ゲーム結果カラー」節）
4. **静かな面を広く、強い色を少なく。** 面の地の色は薄く保ち、強い色は注意が要る所と主ボタンに残す

これに伴い、旧ガイドの「主ボタンは朱」「勝=朱・負=藍」「負傷は赤」は改めた。

### 色の役割とトークン

色は役割ごとに分け、役割には「背景 `name` ＋ 文字 `on-name`」の対のトークンを割り当てる。画面は Material の色名（`purple` `amber` など）ではなく、このトークン名で参照する。

| 役割 | 問い | 表現 | トークン |
|------|------|------|----------|
| 区分 | どの種類か（登録・離脱 / 試合日） | グループ見出し＋境界線。地の色は面との差が小さい（1.1〜1.4）ので、境界線と見出しも併用 | `zone-*` |
| 状態 | どこまで進んだか | チップ（淡い丸角）＋状態アイコン＋文字。線種: 実線=確定、破線=編集中、点線=まだ | `state-*` |
| 離脱 | 何で出られないか | チップ＋アイコン＋文字 | `absence-*` |
| 日付 | 日付の種類 | チップ＋アイコン＋文字。寒色と無彩色のみ | `date-*` |
| 勝敗 | 勝ち負け | 淡い角のバッジ＋1 文字（W / L / D / NG） | `result-*` |
| 操作 | 何をするか | 主=緑の濃い塗り、副=枠、破壊的=赤の枠。いずれも動詞の文字つき | `action`、`border-strong`、`danger-ink` |

- 値はすべて文字 4.5 以上。同値のトークンは役割が違うので別名にしてある（`date-game` と `zone-game`、`date-reserve` と `zone-roster`、`result-win` と `state-done`、`result-loss` と `state-warn`、`result-draw` と `state-neutral`、`date-rain` と `result-nogame`）。片方だけ後で変えられる。
- 時期チップ（試合前 / 試合中）は新しい値を足さず、試合前=`zone-roster`、試合中=`zone-game` を使う。
- **負傷と出場停止は同じ色**（`absence-out`）。「出られない」ことに変わりはないため。見分けはアイコン（hospital-box / gavel）と文字で行う。再調整は鼠、昇格クールダウンは柿。
- 緑は「済」「勝ち」「主ボタン」の 3 つに使う。ボタン（濃い塗り＋アイコン＋動詞）、チップ（淡い丸角＋状態アイコン）、勝敗バッジ（淡い角＋1 文字）の**形**で見分ける。この 3 つの緑を同じ形にしてはならない。
- 赤（暖色）が意味するのは「要確認」「負（L）」「削除」の 3 つ。いずれも「良くない・危険」という同じ向きの意味で、形（チップ / 角バッジ / 枠つきボタン）で分かれる。
- ライトの `absence-out`（負傷）と `state-warn`（要確認）は地色が近い（色差 5.4）。見分けは文字の色・アイコン・ラベルに頼るので、同じ表の同じ列に並べない。

## 2. タイポグラフィ

### フォント選定

```
見出し系 : Shippori Mincho (Google Fonts) — 明朝体、和風の格調
本文・UI : Noto Sans JP — 可読性高く、UI操作に最適
数値・統計: JetBrains Mono / Noto Sans JP — 等幅で統計表が読みやすい
```

### フォントサイズ体系

| 用途 | クラス | サイズ | 行間 | 用例 |
|------|--------|--------|------|------|
| 大見出し | `text-h4` | 2.125rem | 1.3 | ページタイトル |
| 中見出し | `text-h5` | 1.5rem | 1.35 | セクション名 |
| 小見出し | `text-h6` | 1.25rem | 1.4 | カード見出し |
| 本文 | `text-body-2` | 0.875rem | 1.5 | 説明文・通常テキスト |
| 統計数値 | `text-body-2` (mono) | 0.875rem | 1.4 | 打率・防御率等 |
| キャプション | `text-caption` | 0.75rem | 1.4 | 補足・ラベル |
| ラベル | `text-overline` | 0.625rem | 2.0 | テーブルヘッダー |

### 数値表示ルール

- 打率・防御率: `.000` 形式（3桁小数点）
- 本塁打・打点等: 右揃え整数
- 投球数・イニング: 右揃え
- すべての統計数値は等幅フォント推奨

> テーマ名は、ガイドでは `thbigLight` / `thbigDark` と書いてきたが、実装は `light` / `dark`（`defaultTheme: 'light'`）。実装の名前が正。

```ts

  defaultTheme: 'thbigLight',
  themes: {
    thbigLight: {
      dark: false,
      colors: {
        primary: '#1B3A6B',
        secondary: '#4A7A8A',
        accent: '#C0392B',

        background: '#F8F6F1',
        surface: '#FFFFFF',
      },
    },
    thbigDark: {
      dark: true,
      colors: {
        primary: '#4A72B8',       // 藍を明るく
        secondary: '#6AADBE',
        accent: '#E05C4A',
        success: '#7BBF4A',

        error: '#E84040',

### 実装時に定義するもの（`vuetify.ts` に足す値）

実装時、テーマの `colors` に次の値を定義する（現状は未定義のものがある）。**`surface-variant` と `on-surface-variant` は必ず定義する。** 未定義だと Vuetify 4.0.3 の既定値（ライト `#424242` / `#EEEEEE`、ダーク `#c8c8c8` / `#000000`）が効き、本文色を載せると 1.7 / 1.4、面の上の文字が 1.2 / 1.4 になって読めなくなる事故が実際に起きた（`SeasonPortal.vue` の 20 箇所が参照している）。

| 名前 | 用途 | ライト | ダーク |
|------|------|--------|--------|
| `surface-variant` | 表見出し・補助面の地 | `#F1EEE6` | `#2D2D50` |
| `on-surface-variant` | 補助面と面の上の補助文字 | `#4A4A4A` | `#B8B8D0` |
| `link` | リンク文字・選択中のリング | `#1B3A6B` | `#9DBBF2` |
| `border-strong` | 副ボタン・入力枠（非文字 3 以上） | `#857F70` | `#7C7CB0` |
| `danger-ink` | 破壊的ボタン・削除アイコン | `#8a1420` | `#ffb3b8` |
| `text-caption`（改定） | キャプション | `#666666` | `#A0A0B8` |
| `game-home` / `game-visitor`（改定） | スコアボードのチーム色 | `#1B3A6B` / `#46565F` | `#9DBBF2` / `#B4C7D3` |

あわせて、「色の役割とトークン」の表の全トークン（`state-*` / `absence-*` / `zone-*` / `date-*` / `result-*` / `action`）を、**背景 `name` と文字 `on-name` の対**で定義する。`on-name` は Vuetify が自動生成する値に任せず、表の値を明示する（自動生成の文字色は比を保証しない）。

  'state-done': '#ddefc9',
  'on-state-done': '#2f5a12',
  action: '#2E7D32',
  'on-action': '#FFFFFF',
  'surface-variant': '#F1EEE6',
  'on-surface-variant': '#4A4A4A',
  link: '#1B3A6B',
  'border-strong': '#857F70',
  'danger-ink': '#8a1420',
}
```

- ダークの `primary`（`#4A72B8`）は AppBar の白文字には足りる（4.78）が、面の上のリンク文字には使えない（3.07）。文字には `link` を使う。
- `--color-home` / `--color-visitor`（`src/assets/base.css`）は、実装が緑・藍、`ui-design-system.md` §4-3 が藍・朱とずれていた。ガイドを正として、ホーム=藍、ビジター=鼠に揃える（ダークではテーマ別の値を使う）。
- 実装を直したら、全トークンの組が基準（文字 4.5、非文字 3）を満たすことをテストで検算する。

## 付録: アクセシビリティ方針

- コントラスト比: テキスト/背景は WCAG AA 基準（4.5:1以上）、枠・線・面の識別など非文字は 3:1 以上を確保。新しい色の組を足すときは、ライト・ダークの両方で比を計算して確かめる（Vuetify の既定値や薄い tint を地として当てにしない）
- **色だけに意味を背負わせない**: どの色にも、アイコンか文字（または破線・点線などの線種）を併用する。色の違い（緑と赤、負傷と要確認など）は、色覚差や暗い画面で見分けられなくても意味が伝わる作りにする
- 形で見分ける: 同系色を使う要素（緑のボタン・チップ・勝敗バッジ）は、形（濃い塗り＋動詞 / 淡い丸角＋アイコン / 淡い角＋1 文字）を揃えない
- フォーカス表示: キーボード操作時のフォーカスリングを明示
- ツールチップ: アイコンのみのボタンには必ず付与（`v-tooltip`）
- 状態アイコン: アイコン + テキスト/色の組み合わせで単一手がかりに依存しない
